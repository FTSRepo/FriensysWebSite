# Friensys — DESIGN.md

> Design system for the Friensys marketing site (v2).
> Friensys is a **School ERP** for Indian K–12 schools. The site must, within one second,
> tell a principal: *this is serious software that runs my whole school* — and feel
> made by people, not generated by a template.
>
> Direction: **warm editorial, India-rooted, light-first.** Futuristic through restraint
> and precision, not through gradients and glows.

---

## 1. Visual theme & atmosphere

- **Editorial, not flashy.** Think a well-set print magazine for school operators: warm
  paper, ink type, generous margins, hairline rules, a confident serif voice.
- **Operational proof up front.** Real product UI (dashboards, screenshots) is the hero
  imagery — framed in light "browser" chrome on warm paper. The product is the art.
- **Calm and trustworthy.** Lots of negative space. One idea per section. Motion is
  subtle (short fades/translates, never marquee-fast, never bouncy).
- **Human touches:** numbered sections, editorial captions, pull-quotes set in serif,
  asymmetric layouts, a single warm accent used sparingly like a highlighter.
- **Avoid the "AI-generated" tells:** no gradient text, no neon-on-black hero, no emoji
  icons, no vague "aurora/glow" blobs, no generic centered bento of equal cards.

## 2. Color palette (semantic roles)

Light is the default theme. A warm-dark mode may be added later but is not required for v2.

| Token | Hex | Role |
|-------|-----|------|
| `--paper` | `#FBF8F2` | Page background (warm off-white, never pure #FFF) |
| `--paper-2` | `#F3EDE1` | Elevated/section background, chrome bars |
| `--surface` | `#FFFFFF` | Cards, product frames (pure white reads as "screen") |
| `--ink` | `#1B1714` | Primary text, headlines (warm near-black) |
| `--ink-2` | `#5C534A` | Body / secondary text |
| `--ink-3` | `#8A8074` | Muted labels, captions, mono eyebrows |
| `--teal` | `#0C5B52` | **Primary brand** — CTAs, links, active nav, serif accents |
| `--teal-deep` | `#083F39` | Hover/pressed primary, deep fills |
| `--marigold` | `#E89A33` | **Accent** — eyebrow rules, highlights, one data series |
| `--clay` | `#C56A3E` | Tertiary warm — warnings, secondary data, sparing |
| `--line` | `#E5DCCB` | Hairlines, borders, dividers |
| `--ok` | `#3F8F5B` | Success / positive deltas |
| `--danger` | `#C0492F` | Errors / negative (warm red, not pink) |

**Rules**
- Primary actions: solid `--teal` on `--paper`, text `--surface`.
- Accent `--marigold` is a highlighter: eyebrow rules, an underline, one bar in a chart,
  a badge. Never large fills, never body text, never a gradient.
- Never put `--teal` and `--marigold` in a gradient together. Flat fills only.
- Borders are always `--line` at 1px. Depth comes from hairlines + soft shadow, not heavy strokes.

## 3. Typography

| Family | Use | Notes |
|--------|-----|-------|
| **Fraunces** (variable serif) | Display headlines, stat numbers, pull-quotes | Optical sizing on; weight 500–600; use *italic* for the accent word in a headline |
| **Inter** | Body, UI, buttons, nav | 400/500/600 |
| **Geist Mono** | Eyebrows, stat labels, captions, code-ish chrome | uppercase, letter-spacing `.08–.12em`, 11–12px |

**Scale (desktop)**
- Display H1: Fraunces 600, `clamp(40px, 5.2vw, 64px)`, line-height `1.02`, tracking `-.02em`
- H2 section: Fraunces 600, `34–40px`, tracking `-.015em`
- H3 card: Fraunces 600, `18–20px` (or Inter 600 for dense UI cards)
- Lead paragraph: Inter 400, `18px`, line-height `1.6`, color `--ink-2`
- Body: Inter 400, `15–16px`, line-height `1.6`
- Eyebrow / label: Geist Mono, `12px`, uppercase, tracking `.12em`, color `--teal` or `--ink-3`

**Voice:** headlines are plain-spoken and concrete ("Run the whole school, not just the
fees"), never buzzwordy. The italic accent word carries the warmth.

## 4. Components

- **Button / primary:** bg `--teal`, text white, radius `11px`, padding `14×24`, weight 600,
  hover → `--teal-deep`, subtle `translateY(-1px)`. No glow, no gradient.
- **Button / secondary:** transparent, `1px --line` border, ink text. Or a bare
  "text link →" with an arrow for tertiary actions.
- **Eyebrow:** `— LABEL` — a short `34px` marigold hairline + Geist-Mono uppercase label.
  Opens most sections.
- **Card:** `--surface` (or `--paper-2`), `1px --line`, radius `14px`, padding `20–24`,
  shadow `--shadow-sm`. Hover lifts 2px + border darkens to `--ink-3` at low opacity.
- **Product frame:** white card, `1px --line`, radius `18px`, `--shadow-lg`; top chrome
  bar (`--paper-2`, three soft dots, mono URL). Wraps every product screenshot.
- **Icons:** Lucide, 1.5px stroke, `--ink` or `--teal`. **Never emoji.**
- **Stat:** Fraunces number + Geist-Mono uppercase label beneath, separated by vertical
  `--line` rules in a row.
- **Pull-quote / testimonial:** serif (Fraunces) quote, attribution in Inter + mono city.

## 5. Layout & spacing

- **8pt rhythm.** Spacing tokens 4/8/12/16/24/32/48/64/96.
- **Container:** max-width `1200px`, side padding `24px` (mobile) → `56px` (desktop).
- **Section padding:** `96–120px` vertical on desktop, `64px` mobile.
- **Asymmetry is intentional:** hero and product rows use unequal columns (≈`1.05fr / 1.15fr`),
  alternate image side row to row. Avoid perfectly symmetric centered stacks except for CTA.
- **Hairline dividers** separate major sections instead of background color blocks
  (use `--paper-2` blocks only occasionally for rhythm).
- **Numbered sections:** optional mono index (`01 — Products`) for editorial feel.

## 6. Depth & shadow

Depth is soft and warm, never hard or neon.
- `--shadow-sm`: `0 1px 2px rgba(27,23,20,.05), 0 4px 12px -6px rgba(27,23,20,.08)`
- `--shadow-lg`: `0 8px 20px -10px rgba(27,23,20,.12), 0 32px 60px -28px rgba(27,23,20,.28)`
- Borders + paper contrast carry most of the structure; shadow only on cards/frames/popovers.
- No inner glows, no colored shadows.

## 7. Do's & don'ts

**Do**
- Lead with the product. Frame real screenshots in chrome.
- Use the serif for personality, mono for precision, sans for reading.
- Keep marigold rare and deliberate.
- Write concrete, principal-facing copy. Indian context where natural (CBSE/ICSE, ₹, DPDPA).

**Don't**
- No gradient text or gradient buttons.
- No emoji as iconography.
- No pure-black `#000` or pure-white `#FFF` page backgrounds.
- No fast/auto-playing carousels; logo marquee ≥ 90s and pauses on hover.
- No equal-card centered bento as the main product layout.
- No purple/cyan "AI SaaS" palette.

## 8. Responsive breakpoints

| Name | Min width | Behavior |
|------|-----------|----------|
| mobile | 0 | single column, 24px gutters, H1 ~40px, stack hero above product frame |
| sm | 640px | 2-col cards |
| md | 768px | nav expands, 2-col product rows begin |
| lg | 1024px | full asymmetric grid, 56px gutters, H1 up to 64px |
| xl | 1280px+ | max container 1200px centered |

## 9. AI agent prompt guide

When generating or editing Friensys UI, follow this:

> Build a **light, warm, editorial** page for an Indian **School ERP**. Background warm
> paper `#FBF8F2`, text warm ink `#1B1714`. Headlines in **Fraunces** serif (600, tight
> tracking) with **one italic teal `#0C5B52` accent word**; body in **Inter**; eyebrows
> and stat labels in **Geist Mono** uppercase. Primary action = solid teal button.
> Accent = **marigold `#E89A33`**, used sparingly (a hairline rule, an underline, one chart
> bar). Frame real product screenshots in a white "browser" card with `1px #E5DCCB` border,
> rounded `18px`, soft warm shadow. Use **Lucide line icons, never emoji**. Hairline
> dividers, generous whitespace, asymmetric columns. The page must instantly read as
> *serious school-operations software made by people* — no gradient text, no neon-on-black,
> no glow blobs, no equal-card bento.
