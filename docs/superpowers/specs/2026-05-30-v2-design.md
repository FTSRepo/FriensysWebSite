# Friensys v2 Design Revamp — Spec

**Date:** 2026-05-30
**Branch:** `revamp/v2-design`
**Design system:** see `friensys-next/DESIGN.md` (canonical tokens, type, components).

## Problem

The v1 marketing site (built earlier this session on `revamp/competitive-rebuild`)
renders as generic AI-generated dark SaaS: purple→cyan gradient text on near-black,
emoji feature icons, vague glow/aurora surfaces, equal-card bento. It does not feel
human, and it says "dark SaaS" before it says "school software." User is not satisfied.

## Goal

Rebuild the look and feel so the site:
1. Feels **futuristic but human** — made by people, not a template.
2. **Instantly communicates** it is a School ERP for Indian K–12 schools.
3. Avoids every generic-AI visual tell.

## Approved direction (user decisions)

- **Mood:** warm editorial, India-rooted.
- **Theme:** light-first (warm paper). Dark mode optional, not in scope for v2.
- **Palette:** new ownable set — paper `#FBF8F2`, ink `#1B1714`, peacock-teal `#0C5B52`
  (primary), marigold `#E89A33` (accent), clay `#C56A3E`, hairline `#E5DCCB`.
- **Type:** Fraunces (display serif) + Inter (body) + Geist Mono (labels/stats).
- **Imagery:** product UI + editorial graphics only. No people photography. No stock.
  Real product screenshots framed in light browser chrome; tasteful custom graphics/texture.
- A hero mockup in this system was rendered and approved before this spec.

## Scope

In scope (v2 on `revamp/v2-design`):
- New design tokens (`styles/tokens.css`, `app/globals.css`) — light-first warm palette.
- Fonts: add Fraunces; keep Inter + Geist Mono. Update `app/layout.tsx` font wiring.
- Rebuild homepage sections (Hero, TrustStrip, WhyFriensys, ProductBento→product showcase,
  AITeaser, StatsCounter, Testimonials, CTASection) in the editorial system.
- Replace emoji icons with Lucide line icons across `content/*.json` + components.
- Refresh shared UI primitives/`ui/*` (Aurora/Glow/GradientMesh → editorial equivalents
  or removal), Badge, BentoCard, SectionHeading, buttons.
- Roll the system across inner pages: products, products/[slug], school-erp, ai, pricing,
  about, customers, services, security, careers, contact, blog, legal.
- Keep all existing content/data, routes, SEO, schema, forms, analytics intact.

Out of scope:
- New copywriting beyond headline/eyebrow polish (content stays).
- People photography / stock sourcing.
- Dark mode.
- Backend / form-submission changes.

## Carry-over fixes already on `revamp/competitive-rebuild` (preserve)

- framer-motion variant `show` (not `visible`).
- Marquee keyframe named `marquee` (not reserved `scroll`); slow + pause on hover.
- next-themes removed (Chrome `addListener` crash); `data-theme` set on `<html>`.
- Dev/build pinned to `--webpack` (Velite plugin).
- 4 product dashboard mockups; Kaksha (competitor) removed, replaced by School App.

These must remain working after the v2 restyle (the v2 branch is cut from this state).

## Success criteria

- Homepage + all inner pages restyled to `DESIGN.md`, no emoji, no gradient text,
  light warm theme throughout.
- A first-time visitor can tell it's Indian school software within ~1s (headline + framed
  dashboard + School-ERP eyebrow + logos).
- `tsc --noEmit` clean; 0 console errors; 0 broken images; all routes 200.
- Verified visually via browse on every marketing page.

## Section plan (homepage)

1. **Hero** — Fraunces headline w/ italic teal accent, lead, teal CTA + text-link,
   mono stat row, framed live dashboard (asymmetric 2-col).
2. **Logo wall** — calm "trusted by" on paper, fixed slow marquee.
3. **Why / not-just-fees** — editorial 3-col problem→capability, Lucide icons, hairlines.
4. **Product showcase** — large framed screenshots, alternating left/right per product.
5. **AI** — restrained "AI for the admin layer," mono callouts, no neon.
6. **Proof** — stat band + serif principal pull-quotes.
7. **CTA** — warm teal "Book a demo" band.
8. **Footer** — editorial, hairline-divided.
